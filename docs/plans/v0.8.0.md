# codex-day v0.8.0 规划

状态：已实现，待发布验证。

## 版本主题

**个人化与主动提醒**

v0.8.0 把浏览器偏好、价格可信度和每日回顾做成可迁移、可判断、可主动触达的完整闭环，同时继续保持本地优先和只读日志边界。

## 版本目标

1. 用户可以在不同浏览器或设备间迁移本地设置，并在写入前确认导入内容。
2. 用户可以判断每个模型价格快照多久没有核验，同时不会把本地时间判断误解为联网比价。
3. 用户可以通过命令、只读接口或 Windows 托盘查看当日汇总，并选择是否每天提醒一次。

## 交付范围

### 1. 设置导入与导出

- JSON 配置包含应用标识、Schema 版本、导出时间和规范化设置。
- 导入限制文件大小并校验应用标识与 Schema 版本。
- 导入结果先填入设置表单预览，只有点击“保存设置”才写入 `localStorage`。
- 配置可包含币种、汇率、倍率、预算和匿名项目 ID 对应的别名。
- 配置不包含 Token 事件、完整路径、原始 Session ID 或日志内容。

### 2. 定价快照状态

- `config/pricing.json` 为每个模型记录最后核验日期。
- 页面根据可配置阈值显示“快照新鲜”“建议复核”或“快照较旧”。
- 价格表展示每个模型的核验日期。
- 页面明确说明该状态不进行后台联网比价，也不证明价格没有变化。

### 3. 本地每日摘要

- `summary` 命令支持今天或指定本地日期，并可输出 JSON。
- `/api/summary` 返回调用、任务、Token 构成、缓存率、平均量和主要模型。
- 输出不包含项目名称、路径、Session ID 或逐条事件。
- Windows 托盘提供立即查看今日摘要和每日摘要提醒开关。
- 提醒默认关闭；启用后在本地时间 18:00 之后每天最多显示一次。

## 不在 v0.8.0 范围

- 浏览器向服务端写入设置
- 自动联网抓取或覆盖价格
- 公司中转站实际账单对账
- 云端同步、账号体系或多用户通知
- AI 生成的日报文字

## 验收标准

- 设置配置可导出并重新导入，非法、超大或版本不兼容文件会被拒绝。
- 导入不会在用户点击保存前修改现有设置。
- 快照状态与模型核验日期在桌面和手机布局中不溢出。
- 摘要命令与接口对同一日期返回一致汇总。
- 摘要接口和 JSON 输出不包含测试夹具中的路径与 Session ID。
- 托盘脚本通过语法检查，提醒开关默认关闭且同一天不会重复自动提醒。
- Demo、构建产物和完整测试通过，公开文件不包含个人数据。
