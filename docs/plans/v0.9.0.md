# codex-day v0.9.0 规划

状态：已实现，待发布验证。

## 版本主题

**价格复核与长期回顾**

v0.9.0 在不引入后台联网和写入风险的前提下，为价格快照增加可审计入口，同时让每日提醒和趋势周期更适合长期个人使用。

## 版本目标

1. 用户可以检查当前价格快照的完整性、新鲜度与官方来源边界，并预览候选文件的字段变化。
2. 用户可以从 Windows 托盘选择合适的每日摘要提醒时间。
3. 用户可以在仪表盘和海报中查看近 90 天的个人 Token 趋势。

## 交付范围

### 1. 只读价格审计

- `pricing` 命令验证价格数值、核验日期和官方来源 URL。
- 模型会按当前、建议复核、过期、待核验或无效分类。
- `--candidate` 输出当前快照与候选快照之间的字段级差异。
- 审计不联网、不写入配置，也不把本地时间判断描述成在线核验。

### 2. 可配置提醒时间

- 托盘菜单提供 17:00、18:00、20:00 与 22:00 四个本地提醒时段。
- 默认时段保持 18:00，配置仅写入当前用户注册表。
- 切换时间不清除当天已提醒状态，避免同一天重复提醒。

### 3. 近 90 天回顾

- 顶部时间范围加入“近 90 天”。
- 当前周期与上一周期采用相同长度进行比较。
- 趋势、筛选、洞察、CSV 和分享海报沿用同一范围状态。

## 不在 v0.9.0 范围

- 后台自动抓取或覆盖价格
- 公司中转站实际账单对账
- 自定义任意提醒分钟或多次提醒
- 云端同步、多人共享或消息推送
- 自动生成自然语言周报

## 验收标准

- 当前价格快照检查通过，非法候选文件以非零状态退出，源文件保持不变。
- 候选差异按模型、模式和价格字段输出，不泄露个人使用数据。
- 托盘脚本通过语法检查，四个提醒时段均可选择且只保留一个选中状态。
- `?range=90d` 可以直接打开，刷新后范围保持，页面和海报都显示正确周期。
- 桌面与 390px 手机布局无横向溢出，控制台无错误。
- Demo、构建产物、完整测试与确定性构建检查通过。
