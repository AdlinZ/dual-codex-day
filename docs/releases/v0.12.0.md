# Dual Codex Day v0.12.0

v0.12.0 adds an evidence-oriented comparison path for users who also use CC Switch, and brings the Electron usage view closer to the web dashboard's time-range coverage.

## Main changes

- CC Switch reconciliation reads `proxy_request_logs` in read-only mode and limits the comparison to `app_type=codex`.
- Both sides use `input + output` for total Token comparison; cached input remains a separately reported subset.
- Reconciliation supports the selected dashboard range, model breakdowns, call deltas and Token deltas without exposing raw session IDs.
- Electron adds 90-day and custom date ranges.
- The detailed usage view refreshes its local index every 30 seconds while visible.

## Safety boundary

- The CC Switch database is opened with SQLite read-only mode.
- A user-selected database path is stored only in local browser storage for convenience.
- No CC Switch rows are copied into the DCD index, and no source log is modified.

## Validation

- Temporary SQLite fixtures cover Codex filtering, totals, cache subsets, daily groups, model groups and source groups.
- Existing dashboard, indexer, service, profile, Electron, site, tray and container checks continue to pass.
