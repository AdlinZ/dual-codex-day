# Dual Codex Day v0.18.0

v0.18.0 增加 Profile 配置迁移与恢复，用可预览、可回滚的文件流程在不同环境间转移非敏感设置。

## 主要变化

- 从启动中心导出版本化 Profile JSON。
- 迁移 Profile 名称、供应商元数据、运行与用量来源、通用 Codex 配置、Skill/插件状态和用量偏好。
- 导入前显示创建或更新、变更范围、缺少组件与凭据要求。
- 只有用户确认后才应用，缺少的 Skills 和插件不会自动安装。
- 写入前创建本地备份，注册表或 `config.toml` 写入失败时自动回滚。

## 数据边界

- 不导出或读取 `auth.json`、API Key、加密供应商密钥、日志、SQLite 用量数据和启动历史。
- 迁移文件中的敏感字段、原型污染键、未知 Schema 和无效 Profile 设置会被拒绝。
- 自定义环境认证的密钥不随迁移文件移动；新建 Profile 或供应商身份变化后需要重新录入。
- Skill 路径在目标机器上按已安装目录重建，插件状态只应用到已安装插件。

## 验证范围

- 纯数据测试覆盖脱敏导出、格式校验、创建/更新预览、缺失组件、应用、备份与失败回滚。
- Electron 检查覆盖 2 MB 文件上限、短时导入令牌、受限 IPC 和预览确认界面。
- 源码版与 Windows x64 打包版均需完成迁移预览截图验证。
