# Dual Codex Day v0.16.0

v0.16.0 汇总交付用量口径校正、CC Switch 对账、Skills 与插件管理，以及公开产品站点。该版本覆盖仓库中 v0.11.0 至 v0.16.0 的累计变化。

## 用量可信度

- 按 CC Switch 3.19.2 的请求语义识别累计快照、真实模型调用、continuation、fork 和 subagent 日志。
- 默认账号、单个 Profile 与全部账号分别使用独立 SQLite 索引，并保留可追踪的数据来源状态。
- 增加当前日志、历史日志、延后文件和旧版记录清理诊断。
- 只读对比 CC Switch 的日期、模型、调用和 Token 差额。
- 支持近 90 天、自定义范围与用量页自动刷新。

## Skills 与插件

- 统一查看共享、默认账号、Profile、本仓库和系统内置 Skills。
- 显式共享、同步、启停和移入回收站，并显示同名冲突。
- 通过官方 Codex 命令查看、安装、启停和卸载插件。
- 单独展示 Marketplace 可安装插件及其 Skills。
- 自动发现“文档”目录下包含 `.agents/skills` 的项目，扫描过程跳过依赖、构建、版本控制和隐藏目录，并限制遍历深度与数量。

## 公开交付

- 增加响应式 GitHub Pages 产品站点、当前 Electron 截图、Release 下载入口和虚构数据 Demo。
- 增加 Pages 自动部署与本地站点回归检查。

## 安全边界

- 原始 Codex 日志和 CC Switch 数据库保持只读。
- 仓库 Skills 保持只读，系统 Skills 不允许修改。
- 插件管理只调用官方 Codex CLI，不直接复制插件缓存。
- 公开站点与截图不包含本地路径、任务标识或个人用量数据。
