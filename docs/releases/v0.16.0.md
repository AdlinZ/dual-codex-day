# Dual Codex Day v0.16.0

`v0.16.0` automatically discovers repository-level Skills without changing the selected Codex launch directory.

## Highlights

- Scan the user's Documents directory for projects containing `.agents/skills`.
- Label every discovered project separately in the standalone Skills matrix.
- Keep repository Skills read-only while retaining explicit share and Profile sync actions.
- Skip hidden, dependency, version-control and build directories.
- Bound discovery by traversal depth, visited directory count and project count.

Manual project selection remains available for repositories stored outside Documents.
