# Dual Codex Day v0.19.0

v0.19.0 增加只读 Profile 环境体检和脱敏诊断导出，用统一状态解释账号无法登录、入口缺失、组件失效和用量读取异常。

## 主要变化

- 从启动中心检查当前 Profile，并按“正常”“需留意”“需处理”汇总。
- 检查活动配置、运行与用量目录、供应商认证、客户端入口、Skills、插件、用量索引、运行实例和迁移备份。
- 每个分组独立返回结果，插件读取失败不会阻断其他检查。
- 支持导出版本化诊断 JSON，便于提交问题时附带结构化环境状态。

## 数据边界

- 体检过程保持只读，不自动修改配置、安装组件或恢复备份。
- 凭据检查只判断系统安全存储与密钥文件是否可用，不读取凭据值。
- 导出文件移除 Profile 名称、内部 ID、用户名和绝对路径。
- 导出文件不包含认证文件、API Key、加密密钥、日志正文、Session 信息或用量事件。
- 渲染进程只能导出主进程保存的短时报告令牌，不能提交报告内容或目标路径。

## 验证范围

- 纯数据测试覆盖正常、提醒、错误等级和总体状态合成。
- 脱敏测试覆盖 Profile 标识、Windows 路径、用户名和凭据特征。
- Electron 检查覆盖受限诊断 IPC、短时令牌、分组界面与截图场景。
- 源码版与 Windows x64 打包版均需完成 Profile 体检截图验证。
