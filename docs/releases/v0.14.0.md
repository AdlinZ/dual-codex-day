# Dual Codex Day v0.14.0

`v0.14.0` completes cross-Profile Skills visibility by adding installed Codex plugins to the Skills manager.

## Highlights

- Separate views for standalone Skills and plugin-provided Skills.
- Plugin inventory comes from `codex plugin list --json`, so stale cache files do not appear as installed.
- Each plugin row lists all bundled Skills and shows its status in the default Codex environment and every Profile.
- Missing plugins can be installed directly into a target Profile.
- Custom Marketplace sources are registered before installation when the target does not have them.
- Installed plugins can be enabled, disabled or uninstalled for one environment.

Plugin installation and removal use the official Codex CLI. DCD does not copy plugin caches between environments. Start a new Codex chat after plugin changes.
