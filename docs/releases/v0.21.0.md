# Dual Codex Day v0.21.0

v0.21.0 增加手动 Profile 恢复中心，把迁移更新生成的本地备份变成可检查、可预览、可确认的恢复点。

## 主要变化

- 启动中心新增恢复入口，按所选 Profile 列出有效与无效备份。
- 恢复前预览账号设置字段和 `config.toml` 的创建、替换、移除或不变状态。
- 新备份记录文件大小与 SHA-256；旧版备份继续接受结构、身份、TOML 和预览指纹校验。
- 损坏、不完整、属于其他 Profile、路径越界及创建类备份保持不可恢复。

## 恢复边界

- Profile 仍有运行实例时拒绝恢复。
- 确认令牌绑定当前渲染进程，有效期为五分钟；应用前再次检查备份指纹。
- 每次恢复前创建保护备份，失败时自动回滚。
- 只合并目标 Profile 的注册表条目并还原它的 `config.toml`。
- 凭据、日志、用量 SQLite、Session、启动记录、其他 Profile 注册信息和数据目录保持不变。

## 验证范围

- 核心测试覆盖正常恢复、活动实例拦截、路径越界、外来备份、完整性损坏、文件缺失和创建类备份。
- 故障注入验证注册表与 `config.toml` 在写入中断后从保护备份回滚。
- Electron 检查覆盖受限 IPC、短时令牌、恢复中心结构和专用截图场景。
