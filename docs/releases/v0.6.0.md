codex-day v0.6.0 是首个完整的本地服务版本：从一次性 HTML 统计页扩展为 SQLite 增量索引、后台刷新、成本洞察、周期报告、Docker 部署和 Windows 托盘常驻的一体化个人仪表盘。

## 主要变化

- SQLite 只重新解析新增或变化的 Codex JSONL 日志，并自动清理已删除文件对应的索引。
- 本地 HTTP 服务默认仅监听 `127.0.0.1:8765`，提供 `/healthz` 与 `/api/status`。
- 增加 API 等价预计成本、币种/汇率/中转倍率、预算进度和月底预测。
- 增加周报、月报、同期对比、活跃日历以及独立报告海报。
- 增加 Dockerfile 与 Compose：日志只读挂载，SQLite 索引独立持久化。
- 增加 Windows 托盘入口、自动恢复、服务重启、日志入口和可选开机自启。
- 新增 codex-day 几何 Logo，并应用到页面、favicon、README 和托盘。

## 快速开始

```powershell
git clone https://github.com/AdlinZ/codex-day.git
cd codex-day
.\scripts\open-dashboard.cmd
```

需要 Node.js 22.5 或更高版本。Windows 无 Node.js 时仍可回退到 PowerShell 兼容模式。

## 数据与费用口径

- 所有统计来自本机 Codex 会话日志，不会上传日志或 SQLite 索引。
- 缓存 Token 已包含在输入 Token 中，推理 Token 已包含在输出 Token 中。
- 页面费用是公开 API 标价的等价估算，不代表公司中转站、折扣、包量或实际账单。
- 真实生成页面与数据库位于被 Git 忽略的 `dist/` 和 `.codex-day/`，不要将它们公开上传。
