# Dual Codex Day v0.13.0

`v0.13.0` adds local Skills management to the existing profile launcher and usage dashboard.

## Highlights

- Inspect shared, default Codex, Profile-local, repository and bundled Skills in one matrix.
- Detect same-name Skills across physical locations.
- Copy a Skill into the shared user directory or sync it to a selected Codex environment.
- Enable or disable a Skill through Codex `[[skills.config]]` entries.
- Move managed Skills to the Windows Recycle Bin; bundled system Skills are read-only.

Directory changes are explicit. The application does not migrate or delete existing Skills automatically. Restart Codex after changing Skill files or configuration.
