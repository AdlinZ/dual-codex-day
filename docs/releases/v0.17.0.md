# Dual Codex Day v0.17.0

v0.17.0 把现有独立用量索引连接成多账号对比视图，并增加任务级钻取。

## 主要变化

- 在当前日期、模型和项目筛选条件下并列展示默认账号与每个 Profile。
- 每个账号展示 Token、任务、模型调用、缓存率、预计成本和主要模型。
- 点击对比行可切换到对应账号的完整用量视图。
- 最近任务支持打开详情，查看交互回合、模型调用以及输入、缓存、输出和总 Token。
- 单个 Profile 读取失败时保留其他账号的对比结果，并在对应行显示错误。

## 数据边界

- 对比数据继续来自各账号自己的本地 SQLite 索引。
- 任务标识保持脱敏，不展示原始日志路径、会话正文或认证数据。
- 预计成本继续使用本地公开 API 价格快照，不代表实际账单。

## 验证范围

- 纯数据测试覆盖日期范围、模型与项目筛选、聚合、主要模型和任务分组。
- Electron 检查覆盖受限 IPC、账号对比节点、任务详情与截图渲染条件。
- 桌面截图必须确认至少两个账号对比行已经渲染。
