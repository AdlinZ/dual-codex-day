# Dual Codex Day v0.20.0

v0.20.0 重构 Electron 工作区的信息层级，统一启动中心与用量分析的视觉语言，并减少常驻操作和面板边框。

## 主要变化

- 应用级导航相对窗口居中，使用底部指示线表达当前页面。
- 用量账号、时间范围、筛选和导出进入页面标题区，不再占用第二层固定工具栏。
- 用量首屏聚焦核心指标、趋势和成本，账户、模型、任务与周期报告改为标签切换。
- 诊断、CC Switch 对账、设置和导出收进明确的操作菜单。
- 启动中心、账号侧栏、用量页和窗口背景统一为纯白，中性浅灰只用于控件状态。

## 行为边界

- 本版本不改变用量索引、成本估算、Profile、Skills 或插件的数据语义。
- 原有筛选、诊断、对账、海报、CSV 和周期报告功能继续保留。
- 窄窗口隐藏重复的标题栏状态文字，保留运行实例和刷新入口。

## 验证范围

- Electron 静态检查覆盖单层导航、渐进式详情和现有受限 IPC。
- 源码截图覆盖标准窗口、最小窗口、筛选菜单、操作菜单和周期报告。
- 完整测试继续覆盖本地索引、Profile、迁移、诊断、Skills、插件、站点和托盘。
