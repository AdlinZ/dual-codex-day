# Dual Codex Day v0.22.0

v0.22.0 把 Profile 体检结果接入日常启动流程，让账号状态、启动判断和处理入口使用同一套数据。

## 主要变化

- Profile 列表与启动区显示就绪、需留意或不可启动，并给出问题数量。
- 体检项可以进入登录、供应商设置、恢复中心、配置目录、Skills 管理或用量诊断。
- Skills 与插件问题会带着相关名称进入对应页面，减少再次查找。
- 登录、供应商、运行来源、迁移与恢复变更后立即失效旧的就绪缓存。
- Profile 正在运行时，打开按钮旁直接显示“关闭客户端”；一次确认可以关闭该 Profile 的全部活动实例。

## 启动前检查

- 每次启动前重新执行只读体检，不使用列表中的缓存结果决定启动。
- 健康 Profile 直接启动，不增加确认步骤。
- 未登录、组件缺失或用量异常等非阻断项显示详情，用户可以确认继续。
- 配置损坏、运行目录不可用、缺少必要凭据和安全存储不可用会阻止启动。
- 所有处理动作由用户点击触发，不执行无提示修复。

## 安全边界

- 预检和手动体检都不读取、复制或展示登录凭据。
- 处理动作使用固定类型与参数，渲染层不能提交命令、任意文件路径或修改后的报告。
- 诊断导出 schema 升级为 v2，继续移除 Profile 名称、内部 ID、用户名和绝对路径。

## 验证范围

- 单元测试覆盖健康、未登录、配置损坏、缺少凭据、组件缺失和用量异常的阻断判断与动作路由。
- Electron 检查覆盖预检 IPC、就绪摘要、处理按钮、继续启动、Profile 客户端关闭和 Skills 聚焦交接。
- 专用桌面截图覆盖带处理动作和继续启动按钮的体检状态。
