# Dual Codex Day v0.10.1

v0.10.1 补齐了 Electron 控制中心的实例关闭能力，并修复 Windows 上 Codex CLI 无法获得真实交互终端的问题。

## 主要变化

- “运行与最近启动”中的每个运行实例都可以单独关闭。
- 关闭前核对启动记录与进程创建时间，避免 PID 被复用后误关无关程序。
- 先请求正常关闭进程树，客户端未响应时才强制结束。
- 系统默认运行环境增加共享窗口风险提示。
- Windows CLI 使用独立 Windows Terminal 窗口，并通过 PID 回写跟踪实际 PowerShell 进程。
- CLI 启动优先使用系统 Windows PowerShell，不再误用 Codex 内置运行时中的 `pwsh.exe`。
- Electron 精简包包含新增停止图标，并支持在旧包运行时输出到备用目录。

## 验证结果

- 完整 `npm test` 回归通过。
- Codex CLI、独立 VS Code 与独立 Codex 桌面端均完成真实启动和关闭验证。
- Windows Electron 发布包完成启动、界面截图与依赖完整性验证。

## 安全边界

- DCD 只接受自身保存的启动记录 ID，不按账号名或进程名批量结束程序。
- 默认账号、认证文件、供应商密钥和原始用量日志不会因关闭实例而被读取或修改。
- 对无法确认归属的进程，DCD 会拒绝关闭并要求用户回到对应窗口手动退出。
