# Dual Codex Day v0.11.0

v0.11.0 统一了本地 Codex 用量统计与 CC Switch 3.19.2 的请求识别口径，并启用可追踪的本地历史台账。

## 主要变化

- 优先采用 `last_token_usage`，缺失时从 `total_token_usage` 高水位计算增量。
- 过滤重复累计快照，以根任务 UUID 和非零事件序号识别同一请求。
- 对 continuation、fork 和 subagent 日志过滤父任务回放前缀。
- 默认账号、单个 Profile、全部账号分别使用独立索引和明确的数据源范围。
- JSONL 消失后，保留由当前解析器建立的历史事件并标记来源缺失。
- 用量标题与数据诊断会显示当前日志、已保留历史、延后处理和旧版历史清理数量。

## 升级说明

- SQLite 索引自动升级到 schema v4。
- 当前仍存在的 JSONL 会按新口径重建。
- 旧解析器产生且源 JSONL 已消失的记录会被移除，因为无法可靠还原其重复快照和父任务回放关系。
- CC Switch 自身保留的旧历史不会从其私有数据库导入，两个应用的全历史总量仍可能存在差异。

## 验证范围

- 累计快照去重、累计值回退、根任务去重和父任务回放过滤。
- 缺失文件历史保留、重新出现后的替换、Profile 数据源隔离和 v1 至 v4 迁移。
- 数据诊断中的任务数量按去重后的根任务计算。
- 真实 Codex JSONL 与 CC Switch 数据库只读对比。
