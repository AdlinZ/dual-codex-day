# Dual Codex Day v0.15.0

`v0.15.0` makes repository Skills and installable Marketplace Skills visible without mixing them into the installed inventory.

## Highlights

- Choose a project directly from Skills management and immediately scan its `.agents/skills` directory.
- Show repository Skills in a read-only current-project column while keeping share and Profile sync actions explicit.
- List uninstalled plugin bundles from `codex plugin list --available --json` in a separate catalog.
- Install a catalog plugin into the default Codex environment or an isolated Profile through the official CLI.
- Keep temporary Marketplace files, cached plugin versions and true installed state clearly separated.

Start a new Codex chat after installing, sharing or synchronizing Skills.
