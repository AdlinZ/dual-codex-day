# Dual Codex Day v0.24.0

v0.24.0 为本地用量中心补齐周/月周期回顾，可比较当前与上一自然周期、检查预算进度，并回看已经完成的历史周期。

## 主要变化

- 本周和本月按已经过时间与上一周期的相同时段比较。
- 周报和月报展示 Token、预计成本、本月预算进度与周期末预测。
- 主要消耗来源覆盖账号、模型和任务；全部账号与单 Profile 使用相同报告入口。
- 支持逐期回看完整自然周和自然月，并可随时回到当前周期。
- 当前报告与历史报告都可以导出本地 PNG 海报。

## 数据口径

- 自然周从本机时区的周一零点开始，自然月从每月一日零点开始。
- 当前周期对比上一周期的相同已过时长；历史周期比较两个完整周期。
- 周期末预测按当前周期已发生的预计成本和已过时间计算，不代表实际账单。
- 历史周期只显示已记录数据，不展示预测值。
- 账号排行排除读取失败的数据源，也不会重复计算复用系统默认用量来源的 Profile。

## 设置与兼容

- 月预算、成本模式、中转站倍率和首选报告周期继续保存在本机。
- Profile 迁移文件携带首选报告周期；旧版 schema 1 文件缺少该字段时默认使用周报。
- Profile 注册表和用量 SQLite schema 均未变化。

## 验证范围

- 单元测试覆盖自然周边界、本地时区、同周期比较、历史完整周期、空数据、预测和账号读取失败隔离。
- Electron 检查覆盖历史导航、返回当前周期、预算报告以及 Profile 迁移兼容。
- 截图验证覆盖当前周报、当前月报、历史周报、历史月报、最小窗口和历史月报海报。
- Windows 打包验证检查新增图标依赖，并使用打包后的可执行程序完成启动冒烟。
